1# benchmarks
2
3Run from the repo root with `PYTHONPATH=python:.`, pinned to one GPU
4(`CUDA_VISIBLE_DEVICES=0`). Each script's `--help` / docstring has the details.
5
6**`bench_decode_moe.py`** — bs=1 decode tok/s of a served MoE model. Spawns `ft serve`
7per backend and times token arrivals over streamed `/v1/chat/completions`, so numbers
8include the full serving path. AIME-25 prompt, checkpoint-recommended sampling.
9
10```bash
11python benchmarks/bench_decode_moe.py --model /path/to/model --backend offload,cpu,hybrid
12```
13
14**`bench_load_weight_generic.py`** — expert-bank load time: serial vs parallel O_DIRECT
15vs pre-repacked FTW, each mode in its own subprocess. Linux-only; stages the FTW under
16`/var/tmp` (`--ftw-dir` overrides; roughly checkpoint-sized).
17
18```bash
19python benchmarks/bench_load_weight_generic.py --model /path/to/model
20```
21
22**`bench_offload_cache_copy.py`** — synthetic (no checkpoint): per-layer decode expert
23copy cost (`ensure_experts` + `copy_missing`), swept over bank layout x cache slots x
24batch size x miss rate.
25
26```bash
27python benchmarks/bench_offload_cache_copy.py
28```
29
30For host RAM vs PCIe bandwidth and the offload/hybrid backend pick, use `ft bench bw`
31instead — it writes the JSON profile the engine reads.
