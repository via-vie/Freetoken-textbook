1# Quick start
2
3Assumes FreeToken is installed — see [install.md](install.md).
4
5## Launch a server
6
7```bash
8ft serve --model ~/models/Qwen3.6-35B-A3B
9```
10
11`--model` also takes a Hugging Face repo id. Everything else — dtype, attention
12and MoE backends, cache sizes, tool-call and reasoning parsers — resolves from
13the checkpoint and the GPU; see [cli.md](cli.md) for the flags. The server is
14ready when the log reaches `API server is ready to serve on 127.0.0.1:1919`.
15
16## Send a request
17
18Check what is being served:
19
20```bash
21curl http://127.0.0.1:1919/v1/models
22```
23
24Then use that id as the `model` field:
25
26```bash
27curl http://127.0.0.1:1919/v1/chat/completions \
28 -H 'Content-Type: application/json' \
29 -d '{
30 "model": "Qwen3.6-35B-A3B",
31 "messages": [{"role": "user", "content": "What is a Mixture-of-Experts model?"}],
32 "max_tokens": 256,
33 "stream": true
34 }'
35```
36
37FreeToken serves the OpenAI API (`/v1/chat/completions`, `/v1/responses`,
38`/v1/models`) and the Anthropic API (`/v1/messages`,
39`/v1/messages/count_tokens`), so a client library for either works by pointing
40its base URL at the server.
41
42## Chat in the terminal
43
44A simple TUI to interact with the server:
45
46```bash
47ft shell # attach to the server above
48ft shell --model ~/models/Qwen3.6-35B-A3B # start an engine and chat, one process
49```
50
51`/help` lists the in-shell commands. Attach mode needs no GPU, so it also drives
52a server on another machine (`--server URL`).
53
54## Use a coding agent
55
56```bash
57ft launch claude # claude / codex / dsh / hermes / openclaw / opencode
58```
59
60Writes that agent's provider config, installs its CLI if missing, and starts it
61against your server. `--dry-run` previews the changes.
