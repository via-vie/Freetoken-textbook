1# Install
2
3AMD users: see the [AMD ROCm installation guide (WIP)](install_amd.md).
4
5## Requirements
6
7- Linux x86_64, NVIDIA GPU, driver r580+ (CUDA 13)
8- Python >= 3.10, with [uv](https://docs.astral.sh/uv/) recommended (plain
9 `pip` + `venv` works too)
10
11## Method 1: Install from PyPI
12
13```bash
14uv venv && source .venv/bin/activate
15uv pip install "freetoken[accel]"
16```
17
18CUDA kernels are JIT-compiled on first use, need a CUDA 13 toolkit with `nvcc` on PATH.
19
20## Method 2: Install from source
21
22```bash
23git clone https://github.com/FlashML-org/FreeToken.git && cd FreeToken
24uv venv && source .venv/bin/activate
25uv pip install -e ".[accel]"
26```
27
28## Method 3: Nightly wheels
29
30Every night `main` is built into a wheel pair on the rolling
31[`nightly` release](https://github.com/FlashML-org/FreeToken/releases/tag/nightly):
32the `freetoken` runtime (CPython 3.12, Linux x86_64) and the matching
33`freetoken-kernel-cache` with FreeToken's own CUDA kernels prebuilt.
34Install both from the URLs on that release page:
35
36```bash
37uv pip install \
38 "freetoken[accel] @ https://github.com/FlashML-org/FreeToken/releases/download/nightly/<runtime wheel>" \
39 "https://github.com/FlashML-org/FreeToken/releases/download/nightly/<kernel-cache wheel>"
40```
41
42Filenames carry a `+g<sha>` build stamp and change every night, and the `nightly`
43tag moves with them. Pin a wheel URL, never the tag. A local copy of the tag goes
44stale: `git fetch` leaves it alone and `git fetch --tags` refuses to overwrite it;
45refresh it with `git fetch --force origin tag nightly`. `engine-linux_x86_64.json`
46next to the wheels names the current pair for scripts.
47
